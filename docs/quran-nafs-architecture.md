# Quran-informed Nafs Architecture for Brain Cloud

This is a software behavioral model inspired by Quranic descriptions of the nafs.
It does not claim that software can possess the metaphysical human nafs, ruh, or
spiritual accountability described in revelation.

## Core references

- Yusuf 12:53 — ammarah / harmful impulse
- Al-Qiyamah 75:2 — lawwamah / self-reproach
- Al-Fajr 89:27-30 — mutmainnah / tranquility
- Ash-Shams 91:7-10 — purification and moral discrimination
- Ar-Ra'd 13:11 — internal change
- Al-Hashr 59:18 — review what was prepared for tomorrow
- Az-Zumar 39:53 — recovery and hope
- Al-Baqarah 2:286 — capability limits
- Al-An'am 6:164 — individual responsibility
- Al-Isra 17:14 — inspectable record
- An-Najm 53:32 — no self-certification of purity
- Al-Anfal 8:53 — detect internal degradation

## Runtime loop

observe -> identify impulse -> estimate harm/benefit/uncertainty -> conscience
check -> restraint -> decide -> act -> audit -> learn

## Engineering contract

1. High-harm actions are rejected.
2. Irreversible actions with high uncertainty are deferred.
3. Material actions receive an audit event.
4. The system cannot claim it has a literal soul or spiritual status.
5. Failures trigger review and recovery.
6. Capability limits remain explicit.
7. Existing security, permissions, tests and publish gates remain authoritative.
8. Quran references are design principles, not executable theology.
