# Brain Executive Control Plane

## Purpose

The Brain Executive is the company's internal operational decision layer. It
chooses the next highest-value eligible objective instead of waiting for a
human to provide a task.

## Autonomous scope

Brain may independently inspect, prioritise, plan, code, test, repair, verify,
package, deploy through already-authorised infrastructure, monitor, benchmark,
document, and optimise reversible internal operations.

When there is no eligible objective, the Executive enters discovery rather
than fabricating work.

## Non-directive safety gates

The gates do not tell Brain which business objective to choose. They only
classify actions that require authority outside the Executive:

- external financial movement;
- contracts and legally binding commitments;
- regulated representations;
- protected credentials or sensitive data;
- destructive irreversible operations;
- actions prohibited by law or core safety policy.

A gated action remains visible as a decision and is not silently converted
into success.

## Executive cycle

OBSERVE -> ASSESS -> PRIORITISE -> DECIDE -> DELEGATE -> EXECUTE -> VERIFY ->
REPAIR/RETRY -> RECORD EVIDENCE -> LEARN -> REPRIORITISE

## Source of truth

GitHub remains the current code source of truth, but GitHub is not the
company's executive authority. The Executive state and evidence model are
provider-neutral so a future Brain-owned cloud can replace GitHub without
changing the executive contract.

## Success rule

An executive decision is not product success. Product and commercial gates
still require independent evidence, release verification, customer evidence,
delivery evidence, and verified payment where applicable.
