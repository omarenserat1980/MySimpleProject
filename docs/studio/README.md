# BRAIN Studio

Project-owned authoring application for original films.

It is intentionally independent of hosted movie editors, AI video generators,
stock-media services and external production dashboards.

The first implementation exposes the native project model and will grow into:
story editor, storyboard, character bible, scene graph, procedural renderer,
audio workstation, timeline, subtitle system, export and evidence/QC.


## Current native modules
- `brain_v12/media/story_engine.py`
- `brain_v12/media/audio_engine.py`
- `brain_v12/media/render_spec.py`
- `docs/studio/storyboard.html`
