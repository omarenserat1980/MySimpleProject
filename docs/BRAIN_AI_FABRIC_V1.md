# Brain AI Fabric V1

Brain AI Fabric is the governed multi-model, multi-agent, multi-tool layer for Electronic Brain V12.

## Contract
- Free/open-source capabilities are preferred by policy.
- A successful response is not automatically a verified outcome.
- Fallback is bounded.
- Consensus is explicit and evidence-backed.
- External side effects remain disabled by default.
- Evidence receives a deterministic content-derived identifier.

## Flow
Perceive -> Understand -> Memory -> Goal -> Plan -> Route -> Execute -> Verify -> Repair -> Retry -> Learn

The Fabric wraps the existing ModelRouter and BrainAI instead of replacing them, reducing regression risk.
