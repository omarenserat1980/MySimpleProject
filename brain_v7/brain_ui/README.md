# واجهة العقل الإلكتروني المستقلة

هذه الواجهة هي **واجهة محادثة مستقلة للعقل الإلكتروني** وليست جزءاً من ChatGPT.

## المزايا
- واجهة عربية RTL مستوحاة من تجربة تطبيقات المحادثة الحديثة.
- شريط جانبي للمحادثات والمشاريع والمكتبة واستوديو الكود والإعدادات.
- اختيار أوضاع تشغيل للعقل: التفكير، السريع، البحث، البرمجة، المدير.
- محادثة مباشرة مع Backend عبر `BRAIN_API`.
- حفظ عناوين المحادثات محلياً في المتصفح.
- استوديو كود داخل الواجهة لمسار الملف والكود والتعديل.
- يرسل تعديلات الكود إلى نقطة التحقق الحالية في `/api/brain/code/preview`.
- لا ينفذ أوامر shell من واجهة المستخدم، ولا يعرض مفاتيح أو كلمات مرور.
- التغيير الفعلي للكود يبقى محكوماً بطبقة الصلاحيات ونقاط الحفظ والتحقق الموجودة في Brain V7.

## الربط
افتح **الإعدادات** داخل الواجهة وضع عنوان Backend، أو عيّن:

```text
localStorage.BRAIN_API
```

مثال:

```text
https://عنوان-خدمة-العقل
```

## ملف الواجهة
`brain_v7/brain_ui/index.html`

الواجهة منفصلة عن ChatGPT، بينما يمكنها الاتصال بخدمات العقل التي تملكها أنت وتتحكم بها.
