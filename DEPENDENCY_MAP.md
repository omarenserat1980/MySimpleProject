# Dependency Map — Base Expansion V2

## Rule
The foundation must remain Brain-independent at the base layer.

## Initial foundation dependencies
- Python standard library only for the minimal core.
- Optional framework dependencies are not required for the first gate.

## Existing system dependencies
Documented in the repository requirements and module structure; these remain outside the initial foundation core until explicitly integrated.

## Dependency policy
For every future dependency record:
- purpose
- license
- version/pinning strategy
- runtime requirement
- cost
- lock-in risk
- failure mode
- fallback
- security implications

## Principle
BRAIN_OWNED -> FREE_DIVERSE -> PAID_EXTERNAL.
Paid external services are never required for foundation survival when a viable local/open alternative exists.
