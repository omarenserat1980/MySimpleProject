# BRAIN-0/1

The low-level foundation of Electronic Brain. The VM executes bytes; the program can be inspected as 0/1.

Instruction opcodes: NOP, LOAD, STORE, ADD, SUB, CMP, JUMP, HALT, READ, WRITE, VERIFY, TASK.

The first proof program computes 7 + 5 = 12 and executes VERIFY before HALT.

This is a deterministic foundation, not a claim that the entire Electronic Brain has already been converted to machine code.
