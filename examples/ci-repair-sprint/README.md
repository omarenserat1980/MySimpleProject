# CI Repair Sprint — Demo Package

**Status:** Demonstration package only. This is not a customer engagement, production incident report, or claim of paid work.

## Pilot offer

Diagnose and repair one bounded GitHub Actions / Python CI failure.

- **Pilot price:** USD 49–99, to be agreed before work starts.
- **Scope:** one repository, one CI failure class, one focused repair, regression test(s), and a reproducible handoff report.
- **Acceptance:** agreed test command passes; change is isolated and reviewable; known limitations are documented.
- **Excluded unless separately agreed:** production deployment, secrets rotation, broad refactors, paid infrastructure, or guarantees against future failures.

## Required intake

1. Repository URL and target branch.
2. Failing workflow/run URL and permission to inspect the relevant code.
3. Expected behavior and acceptance criteria.
4. Deadline and preferred communication channel.
5. Confirmation that no secrets or personal data should be shared in logs.

## Delivery checklist

- [ ] Capture baseline failure and relevant log excerpt.
- [ ] Reproduce failure with a focused test or command.
- [ ] Identify root cause and explain it plainly.
- [ ] Implement the smallest safe change on a separate branch.
- [ ] Run focused tests, then relevant regression checks.
- [ ] Provide commit/PR link, before/after evidence, and rollback note.
- [ ] Record delivery acceptance and payment evidence separately.

## Commercial truth boundary

An offer is not a customer. A quote is not a contract. A completed technical task is not proof of payment. Record revenue only after independent payment evidence is reconciled. Do not publish customer names, repository details, or logs without permission.
