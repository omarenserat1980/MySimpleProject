# YouTube Execution Plan

The execution-plan compiler is the final boundary between Brain decisions and external actions.

## Principle

Control Plane decides. Execution Plan describes. An authorized executor performs real external actions.

## Standard plan

DRAFT -> RENDER -> QC -> PUBLISH -> MEASURE -> LEARN

Publishing is explicitly marked as requiring authorization. The compiler itself has no side effects.

## Blocked states

Duplicate content, failed production economics, or failed QC produce an empty plan.

## Safety

The plan compiler does not upload to YouTube, create channels, spend money, or modify revenue records. It does not create workers or parallel loops.
