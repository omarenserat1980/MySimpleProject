# Brain Operating Values

The system may be used to build ambitious software and infrastructure, but it
operates only on resources that are owned or explicitly authorized.

Core values:
- service to people
- honesty about what was actually executed
- least privilege
- safety and reversibility
- auditability
- human control over consequential external actions

The project can encode these values in its software gates and operating policy;
it does not claim personal beliefs or religious status.
