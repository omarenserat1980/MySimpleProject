# Autonomous Software Factory

Brain-owned and authorized workloads follow:

SPEC -> ARCHITECT -> CODE -> BUILD -> TEST -> SECURITY GATE -> RELEASE -> DEPLOY -> HEALTH CHECK -> OBSERVE -> REPAIR -> ROLLBACK/RELEASE

The factory is provider-neutral and can target Docker/cloud infrastructure.
Production credentials and infrastructure permissions must be supplied explicitly.
No credential harvesting, authentication bypass, firewall bypass, or control of
third-party systems is part of the factory.
